BEYOND THE BACKPACK — RESEARCH WEBSITE

FILES
- index.html: website content and per-tab media placeholders
- style.css: layout, responsive styles, and placeholder appearance
- script.js: navigation, narration, charts, and local media preview behavior

HOW TO OPEN
1. Extract this ZIP file.
2. Open index.html in a modern browser.
3. Scroll through each navigation tab/section. Every tab includes an image placeholder and an audio placeholder.
4. Use each Choose File button to preview an image or audio recording from your device.

IMPORTANT ABOUT THE PLACEHOLDERS
- Selected image/audio files are previewed locally in your browser only. They are not uploaded to a server and are not saved into the website. Refreshing the page clears the previews.
- To permanently publish media for everyone visiting the website, place the final media files in the website project and update the HTML to point to those files before redeploying.
- Existing embedded YouTube videos and browser-generated narration remain in the media section.
- Internet access is needed for online fonts and embedded videos.
